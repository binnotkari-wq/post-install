# post-install

Kit de post installation, mise en place environnement pour Fedora Atomic et dérivés. Aucune donnée personnelle.

## Configuration OS

```bash
curl -sSL https://raw.githubusercontent.com/binnotkari-wq/post-install/main/OS_config.sh | bash
```

## Configuration environnement

```bash
curl -sSL https://raw.githubusercontent.com/binnotkari-wq/post-install/main/environment_config.sh | bash
```
