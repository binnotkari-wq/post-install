4. Remplacer les dossiers par des liens symboliques

Conserve d’abord les anciens dossiers comme sauvegarde :
bash

sudo mv /var/lib/flatpak /var/lib/flatpak.old
sudo mv /var/lib/containers /var/lib/containers.old

Puis crée les liens :
bash

sudo ln -s /var/data/var-lib-flatpak /var/lib/flatpak
sudo ln -s /var/data/var-lib-containers /var/lib/containers

Pour ton compte utilisateur :
bash

mv ~/.local/bin ~/.local/bin.old
mv ~/.local/share/containers ~/.local/share/containers.old

Puis :
bash

ln -s /var/data/user-.local/bin ~/.local/bin
ln -s /var/data/user-.local-share-containers ~/.local/share/containers

Vérifie les liens :
bash

ls -ld \
  /var/lib/flatpak \
  /var/lib/containers/storage \
  ~/.local/bin \
  ~/.local/share/containers/storage

Ils doivent afficher -> /var/data/....
5. Restaurer les contextes SELinux

Fedora utilise SELinux. Après le déplacement, applique les contextes adaptés :
bash

sudo restorecon -RFv /var/data/var-lib-flatpak
sudo restorecon -RFv /var/data/var-lib-containers
restorecon -RFv /var/data/user-.local/bin
restorecon -RFv /var/data/user-.local-share-containers



Le dernier chemin ne doit être exécuté qu’en tant que ton utilisateur, sans sudo.
6. Tester

Flatpak :
bash

flatpak list

Podman rootless :
bash

podman info
podman ps -a

Podman rootful :
bash

sudo podman info
sudo podman ps -a

Puis redémarre tes conteneurs :
bash

podman start -a

Si tout fonctionne après un redémarrage, tu pourras supprimer les sauvegardes :
bash

sudo rm -rf /var/lib/flatpak.old
sudo rm -rf /var/lib/containers/storage.old
rm -rf ~/.local/bin.old
rm -rf ~/.local/share/containers/storage.old

Point important : les deux stockages de conteneurs sont indépendants :
text

/var/lib/containers/storage              → Podman rootful
~/.local/share/containers/storage        → Podman rootless
